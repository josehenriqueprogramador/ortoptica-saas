# 👁️ Ortoptica SaaS

Plataforma HealthTech com IA para análise ortóptica, tracking ocular e processamento clínico inteligente.

---

## 🚀 Tecnologias

- Laravel
- FastAPI
- MediaPipe
- OpenCV
- React + Vite
- Flutter
- Redis
- MySQL
- Qdrant
- Docker

---

## 🧠 Arquitetura

```text
Flutter/Web
     ↓
Laravel API Gateway
     ↓
FastAPI IA Service
     ↓
MediaPipe/OpenCV
     ↓
Qdrant + MySQL + Redis
```
